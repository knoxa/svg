See also the [Tilings Encyclopedia](https://tilings.math.uni-bielefeld.de/) pages for [Penrose Kite Dart](https://tilings.math.uni-bielefeld.de/substitution/penrose-kite-dart/) 
and [Ammann A4](https://tilings.math.uni-bielefeld.de/substitution/ammann-a4/).
