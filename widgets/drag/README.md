# Drag and Drop

JavaScript for drag and drop: [drag.js](drag.js). This depends on the [canvas widget](../canvas).

## Examples

A simple example is [testdrag.svg](testdrag.svg).
The white and green circles can be dragged. The pink circle and yellow square can't.
The action on drop is to print the SVG for the drop target to the browser console.

A more complex example is [pentominoes.svg](pentominoes.svg). This shows a solution to the 6 x 10 [pentomino puzzle](https://en.wikipedia.org/wiki/Pentomino).
Drag the pieces away from the completed board, then try finding a different solution. There are keyboard controls to flip and rotate the pentomonies.
While holding the left mouse button down, press:

* __Q__ to flip in the horizontal axis.
* __A__ to flip in the vertical axis.
* __Z__ to rotate clockwise by 90 degrees.
