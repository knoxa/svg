# Hexgrid

A clickable hexagonal tiling in the background. See [test.svg](https://knoxa.github.io/svg/widgets/hexgrid/test.svg).

## Issues

1. It works with **preserveAspectRatio** set to *none*, and some other combinations of **preserveAspectRatio** and **viewbox**.
How these setting affect the position of the grid in relation to browser events is not yet understood.

1. Size of hexagon tiles is fixed. It should be possible to parameterise this, or include scaling of the background to achieve the same effect.
