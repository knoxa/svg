# Symmetries of the Euclidean plane

Filenames are the [IUCr Symmetry notation](https://en.wikipedia.org/wiki/International_Union_of_Crystallography#IUCr_Symmetry_notation).

The 17 [wallpaper groups](https://en.wikipedia.org/wiki/Wallpaper_group):

* Reflection: [pmm](pmm.svg) (\*2222), [p3m1](p3m1.svg) (\*333), [p4m](p4m.svg) (\*442), [p6m](p6m.svg) (\*632), [cm](pm.svg) (\*\*)
* Rotation: [p2](p2.svg) (2222), [p3](p3.svg) (333), [p4](p4.svg) (442), [p6](p6.svg) (632)
* Mixed: [cmm](cmm.svg) (2\*22), [p31m](p31m.svg) (3\*3), [p4g](p4g.svg) (4\*2), [pmg](pmg.svg) (22\*) 
* Glide Reflection: [pgg](pgg.svg) (22x), [cm](cm.svg) (\*x), [pg](pg.svg) (xx)
* Translation: [p1](p1.svg) (o)

Each example defines a fundamental region and uses the symmetries to draw a patch covering a rectangle that will tile the plain.
This rectangle is captured as an SVG *pattern* that may used as the background for any shape.
